# 坦克大战 (Tank Battle)

一个使用原生 HTML5 Canvas + JavaScript 编写的经典「坦克大战」(Battle City) 风格小游戏，单文件实现，无任何外部依赖。

## 在线试玩

直接打开 `index.html` 即可开始游戏，也可以托管到 GitHub Pages 后通过浏览器游玩。

## 操作方式

| 操作 | 按键 |
| --- | --- |
| 移动 | 方向键 或 `W` `A` `S` `D` |
| 射击 | 空格 或 `J` |
| 暂停 / 继续 | `P` |
| 开始 / 返回标题 | `Enter` 或点击画面 |

## 玩法说明

- 消灭关卡内所有敌人即可过关，保护己方基地（金色鹰）不被摧毁。
- 砖墙可被击毁，钢墙不可摧毁（最高级火力可击穿），水阻挡坦克但子弹可越过，草丛会隐藏坦克。
- 每关 20 名敌人，敌人分四种：普通、快速、火力、装甲；击毁「装甲」敌人会掉落道具。
- 道具效果：⭐ 武器升级 · 🛡 护盾 · 铲子（基地变钢墙）· 坦克（加命）· 时钟（冻结敌人）· 手雷（清屏）。
- 玩家初始 3 条命，阵亡后会在出生点复活。

## 文件结构

## 技术要点

- 纯 Canvas 绘制，无图片资源；音效由 Web Audio API 实时合成。
- 固定逻辑步长 + 按帧时间缩放，保证不同刷新率下表现一致。
- 瓦片碰撞检测 + 子弹分步移动，避免高速穿透。
